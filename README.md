# BooksCollector

## Описание
Проект представляет собой класс `BooksCollector` для управления коллекцией книг.  
Класс позволяет:
- добавлять книги;
- устанавливать им жанры;
- получать книги по жанру;
- получать список книг для детей (без возрастного рейтинга);
- добавлять и удалять книги в избранном.

## Технологии
- Python 3
- pytest

## Установка и запуск тестов

### Установка pytest
pip install pytest

### Запуск тестов
pytest tests.py -v
